## Project ROI Extraction

The transcript’s practical yield is not a prediction about Kimi K3. It is a reusable way to evaluate fast-moving capability claims before they alter project behavior.

1. **Model substitution is a governance event.** A cheaper or more capable model can change data residency, provider dependence, safety behavior, logging, permissions, and human override. The project should treat “Can we swap the model?” as a review question, not an automatic optimization.
2. **Provenance belongs beside performance.** A model can look strong on benchmarks and still be unusable for a governed workflow if its training provenance, license, security history, or deployment chain is unclear. This strengthens the existing acceleration-source verification gate.
3. **Open weights create an authority surface.** Downloadability changes who can run, modify, monitor, and stop a system. The relevant project question is not whether open weights are good or bad, but which authority boundaries remain visible after deployment. This reinforces the existing permissions-and-authority review gate.
4. **Cost-performance claims should become test design.** The episode’s capital-efficiency argument is useful only as a hypothesis: compare task-level quality, latency, total operating cost, failure recovery, review burden, and switching cost—not parameter counts or valuations.
5. **Mixed-topic acceleration packages need seam separation.** Technical reporting, geopolitical interpretation, medical claims, and UAP speculation borrow credibility from one another when bundled. Keeping those seams separate is itself a research-quality control for Singularity Science.

### ROI disposition

- **Preserve:** the new Model Substitution Readiness Gate, alongside the existing acceleration-source verification and permissions/authority gates.
- **Lane-test-ready:** use the model-substitution question in Media Production or other lanes only as an internal review prompt, pending lane-owner and security approval.
- **Needs-verification:** Kimi K3 benchmark/cost claims, the Hugging Face incident, alleged distillation, and White House policy claims.
- **Do not extract:** longevity numerical forecasts, UAP conclusions, and “irreversible turning point” rhetoric.
