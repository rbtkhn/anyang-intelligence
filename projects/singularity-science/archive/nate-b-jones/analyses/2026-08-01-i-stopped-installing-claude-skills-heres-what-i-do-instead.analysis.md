# Nate B. Jones Analysis: Govern Skill Adoption as Capability Transfer

## Decision Compression

- What changed: Installing a skill is reframed as importing an operational capability and its embedded judgment, not merely copying useful instructions.
- Reusable mechanism: Apply a governed skill lifecycle covering purpose, provenance, activation precision, human inspectability, lineage, representative tests, and portfolio interaction audits.
- Decision implication: Compare the source-derived lifecycle with existing repository skill governance before proposing any new gate or audit.
- Evidence still missing: Primary product documentation, code-level security review, representative activation and quality tests, portfolio-conflict fixtures, review burden, and independent corroboration.
- Recommended disposition: primitive-candidate

## Lead Judgment

The strongest reusable mechanism is a skill adoption and portfolio-integrity review that treats every skill as a bounded transfer of judgment and capability. Claims about universal agent behavior, security, adoption timing, percentage splits, performance degradation, and the speaker's own tools remain provisional.

## Controlling Object

Whether a skill is sufficiently purposeful, attributable, inspectable, activatable, compatible, and tested to join an agent's capability portfolio without importing hidden authority or degrading other work.

## Seam Analysis

### Seam: provenance before capability transfer

- Core claim: Installing an external skill imports operational assumptions and judgment, so source trust, purpose, tools, shortcuts, and authority must be inspected first.
- Likely durable: Capability imports should have visible provenance, intended use, bounded authority, and reviewable contents.
- Likely speculative: That untrusted skill repositories typically fail or contain malicious instructions.
- Verification burden: Inspect source lineage, files, scripts, tool calls, permissions, tests, and release history; test in a bounded environment.
- Primitive opportunity: Adoption receipt recording purpose, provenance, authority, contents, tests, reviewer, and rollback.
- Lane-safe routing opportunity: Ask what capability and judgment enter the system, from whom, for which job, and with which authority.
- Membrane risk: “Trusted source” can become social trust without technical review; skill installation may expose tools, data, or execution paths.
- ROI disposition: lane-test-ready

### Seam: dual-audience progressive disclosure

- Core claim: A skill should expose concise discovery metadata first, load its operating instructions only when matched, and keep referenced detail available without forcing it into every task.
- Likely durable: Discovery, instruction, and resource layers serve different purposes; both agent usability and human inspectability matter.
- Likely speculative: The exact loading behavior across every named product and the degree of performance loss caused by broad or long skills.
- Verification burden: Confirm current product contracts and test trigger precision, missed activations, false activations, context use, and task quality.
- Primitive opportunity: Skill quality gate covering discoverability, bounded scope, instruction clarity, progressive disclosure, examples, counterexamples, and human auditability.
- Lane-safe routing opportunity: None until compared with existing repository skill requirements.
- Membrane risk: Concise metadata can hide broad downstream authority; human-readable prose may still be operationally ambiguous.
- ROI disposition: primitive-candidate

### Seam: judgment externalization and lineage

- Core claim: Voice or unstructured explanation can externalize tacit judgment into a repeatable skill, while visible lineage distinguishes inherited mechanisms from local goals and changes.
- Likely durable: Capturing purpose, decision criteria, examples, counterexamples, ancestry, and modifications improves reviewability.
- Likely speculative: That voice is uniquely transformative or that a skill builder reliably converts informal speech into production-quality instructions.
- Verification burden: Compare generated skill behavior with operator intent across representative cases and review lineage accuracy.
- Primitive opportunity: Skill-lineage and intent receipt covering upstream source, retained mechanism, modifications, rationale, tests, and reviewer.
- Lane-safe routing opportunity: Ask what judgment was inherited, what changed locally, and how the change was tested.
- Membrane risk: A derivative skill may import copyrighted material, incompatible permissions, or unacknowledged authority from its source.
- ROI disposition: lane-test-ready

### Seam: portfolio audit before additive repair

- Core claim: When results degrade, inspect the current skill portfolio for activation gaps, overlap, contradictory instructions, duplication, and context burden before installing another skill.
- Likely durable: Read-only inventory before mutation and one-rule-one-home governance reduce hidden configuration debt.
- Likely speculative: That models “average out” conflicting skills in a predictable way or that the speaker's audit catches material conflicts reliably.
- Verification burden: Seed activation, duplication, contradiction, scope-overlap, and context-burden fixtures; measure detection accuracy, false positives, and post-fix regressions.
- Primitive opportunity: Skill portfolio integrity audit with inventory, provenance, activation map, conflict evidence, proposed resolution, approval, and retest.
- Lane-safe routing opportunity: None until compared with the existing context-integrity and skill-validation stack.
- Membrane risk: Automated conflict resolution may erase intentional specialization, alter authority, or rewrite user-owned instructions.
- ROI disposition: primitive-candidate

### Seam: adoption and promotional rhetoric
