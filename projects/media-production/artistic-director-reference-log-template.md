# Artistic Director Accepted / Rejected Reference Log

Use this log to record why a visual reference was useful, rejected, or held.
The purpose is to build reviewable creative memory, not to create a style-copy
library or imply rights to reuse an asset.

## Entry examples

```text
Accepted because: strong negative space makes the central idea legible at thumbnail size.
Rejected because: beautiful texture overwhelms the narrative subject and creates visual noise.
Held because: the composition is promising, but source rights and likeness status are unresolved.
Reference-only because: the principle is useful, but the source should not be imitated directly.
```

## Boundary

Do not commit private client references, confidential assets, personal information,
or unlicensed source material merely because it influenced a decision. Store
restricted references in an approved private location and retain only a safe,
generic lesson in shared project memory.
