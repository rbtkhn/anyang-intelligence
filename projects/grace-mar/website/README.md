# Grace Mar Landing Page

Local website source for the first Grace Mar umbrella landing page.

## Boundary

This source is local review material. It does not authorize hosting,
deployment, DNS changes, Google Workspace setup, analytics, forms, commerce,
customer contact, or Grace Gems storefront changes.

The first release is intentionally static:

- Grace Mar umbrella introduction;
- Grace Gems flagship-brand overview;
- no form or customer-data collection;
- no analytics SDK, advertising pixel, checkout, cart, or account system;
- no active email route; and
- no claim that Grace Mar is an LLC.

## Commands

```bash
npm install
npm run build
npm test
```

`npm test` builds the site and verifies the rendered landing page plus the
first-release no-data boundary.

## Hosting

`.openai/hosting.json` declares no D1 or R2 resources. Any Sites project,
saved version, deployment, custom-domain binding, DNS change, or public release
requires a separate approval packet with exact scope and stop conditions.
