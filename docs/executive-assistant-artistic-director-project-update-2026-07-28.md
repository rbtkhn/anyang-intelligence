# Artistic Director Project Update for Executive Assistant

**Date:** 2026-07-28  
**Project:** Human Artistic Director onboarding and AI apprenticeship  
**Status:** Phase 1 sent; awaiting human response and repository evidence  
**External action:** None currently authorized

## Executive summary

Anyang Intelligence has hired a human Artistic Director to develop a creative
practice and train an Artistic Director AI agent. The onboarding is intentionally
starting with a small, job-neutral studio-formation phase before any Grace Gems
campaign or live client work begins.

The human's studio is not a separate repository. It is an
`artistic-director/` folder inside the existing `JK3303/OB1` repository. The
folder is allowed to develop in the human's own direction; exact synchronization
with Anyang Intelligence documents is not required.

## What has been completed

- The Phase 1 onboarding packet was written and committed.
- A Claude Code prompt was prepared so the human can scaffold the starter
  folder without changing OB1's existing infrastructure.
- The starter scope was reduced to six Markdown files rather than a large
  operating system.
- A job-neutral calibration exercise was prepared to teach the human how to
  critique and revise AI-generated creative work.
- The onboarding instructions and cover message were sent to the human.

## Current state

The project is waiting for the human to:

1. create the `artistic-director/` folder inside OB1;
2. personalize the starter files;
3. complete the calibration exercise;
4. record what the AI learned and misunderstood; and
5. return the repository and commit evidence.

No Artistic Director runtime activation, Grace Gems task, client brief, client
contact, publication, delivery, spending, or external dispatch is active.

## Executive Assistant implications

For now, the Executive Assistant should:

- treat the human's onboarding as internal development work;
- avoid sending the Grace Gems campaign or website brief;
- avoid giving the human or AI private Grace Gems material;
- avoid treating the existence of a repository folder as activation;
- preserve the sole-normal-interface boundary for any future external work; and
- wait for a separate approved dispatch before contacting Grace Gems about this
  project.

The Executive Assistant is not expected to review, edit, task, or approve the
human's personal creative studio during this waiting period. Any observation or
feedback should remain bounded and attributable.

## Relay model

Once a bounded task is approved, the Executive Assistant will serve as the
communications and evidence relay between the Chief Executive and the human
Artistic Director:

```text
Chief Executive instruction
  -> Executive Assistant transmits it faithfully
  -> human Artistic Director performs the work
  -> Executive Assistant returns the output and evidence
  -> Chief Executive evaluates the result
```

The Executive Assistant should not silently rewrite the objective, add creative
direction, approve the output, expand the scope, or compress the human's
response in a way that removes provenance. Any changed scope, unclear
authority, private-data request, rights issue, or external implication should
be held and returned for review.

Use the [Executive Assistant–Artistic Director Relay
Protocol](executive-assistant-artistic-director-relay-protocol.md) when this
loop becomes active.

## What happens after the response

The next review will check whether the human can:

- distinguish prompts, memory, creative decisions, and permissions;
- generate materially different concepts with AI;
- provide specific creative critique;
- identify what the AI misunderstood;
- keep sensitive information out of the public repository; and
- recognize when work must stop for human permission.

If Phase 1 is satisfactory, a separate Phase 2 Grace Gems campaign brief can be
considered. That campaign would still require its own scope, client direction,
source boundary, review gates, and publication authority.

## Current instruction

Hold all Artistic Director-related external communication and client delivery
until the Phase 1 response is received and reviewed. No action is required from
the Executive Assistant at this time.
