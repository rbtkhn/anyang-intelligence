# Cover Message for Phase 1 Onboarding

Hi JK,

Welcome to the Artistic Director role.

Your first assignment is to create a small creative studio inside your existing
OB1 repository. This is a setup and learning phase, not a live project. The
goal is to help you become comfortable working with AI and begin teaching an
AI your creative judgment.

Please complete these steps:

1. Open your `JK3303/OB1` repository.
2. Open Claude Code from the root of that repository.
3. Copy and paste the full **Phase 1 Claude Code Prompt** into Claude Code.
4. Read the six files Claude Code creates under `artistic-director/`.
5. Replace the TODO prompts with your own words.
6. Complete the separate **Phase 1 Calibration Exercise**.
7. Commit the work when you are satisfied with it.
8. Send back the repository link, commit link, exercise link, lessons link,
   and a short answer to: “What did you learn about working with AI?”

Please keep this first phase simple. Do not install additional software, deploy
anything, use API keys in the repository, or change the existing OB1 setup
unless you understand exactly why you are doing it.

Because the repository is public, do not add passwords, private information,
customer or project material, confidential conversations, or unlicensed
creative references.

You do not need to produce impressive final art. Clear observations about what
the AI did well, what it misunderstood, and how you want it to improve are the
most valuable results of this phase.

Take the time to make the studio feel like yours. The initial structure is only
a starting point; it can grow after you have completed the first exercise.
