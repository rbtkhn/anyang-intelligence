# Agent Contradiction-Preflight Contract

After intent recovery and before consequential elicitation or execution, run
the contradiction preflight only when a material factual request assertion
conflicts with, or may supersede, controlling repository state.

The calling agent must:

1. inspect the smallest relevant controlling surface;
2. normalize explicit scalar assertions and facts into a packet;
3. name provenance and authority roles without asking the checker to infer
   precedence;
4. route missing or stale control to neutral evidence intake;
5. route one request-versus-control conflict to decision navigation;
6. hold conflicting controlling sources for named authority resolution.

Skip the preflight for exact menu selections, clear commands without a factual
conflict, and ordinary missing preferences.

Every result has `authority_effect: none`. It never grants mutation, execution,
publication, correction, or reusable capability authority. Durable correction
requires the repository's separate authorized state-transition workflow.
